# Stranger Things LGC (Next.js)

Application Next.js (App Router) qui propose un chat avec des personnages inspirés de Stranger Things via l'API Gemini.

## Démarrage
- Copier votre clé dans `.env.local` sous la variable `NEXT_PUBLIC_API_KEY`.
- Installer les dépendances : `npm install`.
- Lancer le serveur de dev : `npm run dev` (http://localhost:3000).

## Scripts utiles
- `npm run build` : build de production.
- `npm run start` : démarre le serveur après build.
- `npm run lint` : lint Next.js/React.
